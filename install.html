Use

  1. Open any video page on jw.org — works with both /finder?lank=… share links and library URLs like …/videos/#en/mediaitems/…/pub-xxx_VIDEO.
  2. Click the bookmark. It reads the LANK from the URL, hits the mediator API, downloads the VTT, strips timestamps/cue numbers/tags, dedupes rollup lines, and copies the result.
  3. An alert confirms how many lines were copied. If the API reports no subtitle track, you'll get a "no subtitles" alert — that's your cue to fall back to whisper.

Notes

  • Language: uses the wtlocale URL param when present, otherwise maps the page's <html lang> (en→E, es→S, fr→F, de→X, pt→T, it→I), defaulting to E. Edit the M map in the code to add locales.
  • Scope: must be run on a jw.org page (same-origin-ish context for fetch + a focused document for the Clipboard API). There's an execCommand fallback if navigator.clipboard is blocked.
  • Output: one sentence per line. Caption fragments are joined and re-split on sentence-ending punctuation; abbreviations (Dr., a.m., e.g.) and initials are shielded from false breaks, and hyphen-split words are rejoined. Rollup duplicates and HTML tags are removed.
  • No-subtitles fallback: when the API has no subtitle track, the bookmarklet instead copies a jwt '<mp4-url>' command to your clipboard. Paste it into Terminal to download the smallest MP4 and transcribe it with mlx-whisper; the transcript is put on your clipboard via pbcopy. Requires the shell function below in your ~/.zshrc and a working mlx_whisper install.
jwt() {
  local tmp; tmp=$(mktemp -d)
  echo "Downloading..."
  curl -sL "$1" -o "$tmp/v.mp4" || { echo "download failed"; return 1; }
  mlx_whisper "$tmp/v.mp4" --model mlx-community/whisper-small.en-mlx \
    --output-format txt --output-dir "$tmp"
  pbcopy < "$tmp/v.txt" && echo "Transcript copied to clipboard."
  rm -rf "$tmp"
}
