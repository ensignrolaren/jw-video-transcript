Transcript → Clipboard

jw.org video pages · fetches the VTT via the mediator API · copies plain text

Install

Drag this link to your bookmarks bar:

📋 Copy Transcript

On mobile, or if dragging doesn't work: copy the code below, create a new bookmark manually, and paste it as the URL.

Use

  1. Open any video page on jw.org — library URLs (…/videos/#en/mediaitems/…/pub-xxx_VIDEO), /finder?lank=… share links, article pages with a download dropdown, news-release pages (which carry only a docid), and Bible introduction videos on wol.jw.org.
  2. Click the bookmark. It reads the LANK from the URL, hits the mediator API, downloads the VTT, strips timestamps/cue numbers/tags, dedupes rollup lines, and copies the result.
  3. An alert confirms how many sentences were copied. The video's title lands on the first line, then a blank line, then the transcript. If the API reports no subtitle track, you'll get a "no subtitles" alert — that's your cue to fall back to whisper.

Notes

  • Language: uses the wtlocale URL param when present, otherwise maps the page's <html lang> (en→E, es→S, fr→F, de→X, pt→T, it→I), defaulting to E. Edit the M map in the code to add locales.
  • Scope: must be run on a jw.org page (same-origin-ish context for fetch + a focused document for the Clipboard API). There's an execCommand fallback if navigator.clipboard is blocked.
  • Output: one sentence per line. Caption fragments are joined and re-split on sentence-ending punctuation; abbreviations (Dr., a.m., e.g.) and initials are shielded from false breaks, and hyphen-split words are rejoined. Rollup duplicates and HTML tags are removed.
  • No-subtitles fallback: when the API has no subtitle track, the bookmarklet instead copies a jwt '<mp4-url>' '<title>' command to your clipboard. Paste it into Terminal to download the smallest MP4 and transcribe it with mlx-whisper; the result is reflowed to one sentence per line and put on your clipboard via pbcopy.

Whisper fallback setup

Only needed for videos with no subtitle track. Requires Homebrew and macOS.

brew install pipx && pipx ensurepath
pipx install mlx-whisper

Then source the shell function from your ~/.zshrc:

source ~/path/to/jw-video-transcript/jwt.sh

Source it — don't paste the function body into ~/.zshrc. jwt.sh looks for reflow.py next to itself, and a pasted copy won't find it (or pick up later fixes). If you must paste, set JWT_REFLOW to the full path of reflow.py.
